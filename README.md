# MODAÉ — Diseño web de moda

Página web estática para un proyecto académico de diseño web.

## Archivos
- `index.html`: estructura y contenido de la página.
- `style.css`: estilos, colores, distribución y adaptación a móviles.

## Cómo verla
Abre `index.html` en un navegador.

## Publicar con GitHub Pages
1. Sube `index.html`, `style.css` y `README.md` a un repositorio de GitHub.
2. Entra en **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.

Proyecto académico. MODAÉ es una marca ficticia creada para fines educativos.
